## Explicación: val vs var
- `nombre` y `precio` utilizan `val` porque sus valores no cambian durante la ejecución del programa.
- `cantidad` utiliza `var` porque representa un estado mutable que cambia cuando se modifica el carrito.
- La reasignación de una propiedad `val` ocasiona un error de compilación.
